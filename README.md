# Telecom Customer Churn Prediction

## Overview

This project predicts whether a telecom customer is likely to churn using machine learning classification models.

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost Classifier

## Dataset

The project uses a synthetic telecom customer churn dataset containing 100,000 customer records.

## Model Performance

| Model | Testing Accuracy | F1 Score |
|---|---:|---:|
| Logistic Regression | 72.35% | 0.5309 |
| Decision Tree | 72.99% | 0.6164 |
| Random Forest | 76.02% | 0.6075 |
| XGB Classifier | 76.01% | 0.6073 |
